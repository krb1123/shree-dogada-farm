Last reviewed: 29 October 2026. This list reflects services identifiable from the current code and configuration. Confirm actual production vendors and account settings before launch.

Current/conditional service providers

  • Application hosting: Render is named as the current public deployment URL in configuration. It may process server requests and application data if this is the active host.
  • Database: SQLite is used by default; if DATABASE_URL is configured, the chosen PostgreSQL provider processes stored order, inquiry and livestock records. Identify that provider in production.
  • OpenStreetMap tile service: map tiles are requested by checkout to display the map.
  • OSRM public routing demo: checkout sends selected coordinates to calculate road distance and delivery fee. The public demo is not guaranteed for production use.

No advertising analytics, email marketing platform, AI processor or payment gateway integration is configured in the reviewed application code. If you add one, update this list before enabling it. Hosting and routing providers may change; this page should be kept current.
